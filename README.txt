KJ Visual Studios - one-page booking site

index.html is ONE self-contained file: the photos and the favicon are built in,
so it works when double-clicked, uploaded to any host, or pushed to GitHub.

OPEN IT: double-click index.html (extract the zip first).

DEPLOY: put index.html in a folder by itself and upload that folder to Vercel,
Netlify (app.netlify.com/drop), Cloudflare Pages or GitHub Pages.
Note: Vercel's free Hobby plan is for non-commercial use only.

EDIT TEXT: open index.html in a text editor and find the block
"EDIT THIS BLOCK FOR EACH CLIENT": name, WhatsApp number, services ("Ask for price"),
hours and social links. To show social buttons, fill in the "socials" line, e.g.
  socials: [ { label: "Instagram", url: "https://instagram.com/yourpage" } ]
